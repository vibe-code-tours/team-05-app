# CrossMart
### Myanmar's Most Trusted Cross-Border Marketplace

**The Problem:**
- Fragmented e-commerce (Facebook, Viber, Messenger)
- Lack of trust and high scam rates
- "Black Box" shipping with no visibility
- Seller burnout from manual order tracking

<!-- slide -->
# The CrossMart Solution

A unified platform combining:
1. **Verified Ecosystem** - Strict seller verification
2. **Transparent Cargo Tracking** - Visual, milestone-based updates
3. **Authentic Products** - Quality assurance

We act as the trusted intermediary between Buyers and Sellers.

<!-- slide -->
# Three Core Product Types

Our platform caters to the unique Myanmar market model:

1. **📦 In-Stock**
   - Local inventory for immediate dispatch.
2. **✈️ Cargo Items**
   - Cross-border goods (e.g., from Bangkok) requiring detailed milestone tracking.
3. **🔥 Promotion Opportunities**
   - Flash pre-buys spotted abroad by verified sellers.

<!-- slide -->
# Key Features (Phase 1)

- **Trust & Safety:** Strict Seller Verification pipeline
- **Premium Buyer Experience:** Modern, glassmorphic UI with micro-animations
- **Deep Search:** Advanced categorization and filtering
- **The Core USP:** End-to-end Cargo Tracking Module

# Technical Architecture

**Frontend:**
- Next.js 15 (App Router), React, TypeScript
- TailwindCSS, shadcn/ui

**Backend:**
- NestJS (TypeScript), PostgreSQL
- Prisma ORM
- BullMQ for background jobs

**Ops & Caching:**
- Docker, Coolify
- Redis, Cloudflare (DNS/CDN)
